AsianScore Open Sports Analytics · Ruby Gem

asianscore_quant

Zero-dependency Ruby quantitative sports analytics gem & live ledger client for AsianScore — Power devigging, Dixon-Coles xG matrix, fractional Kelly criterion, and Brier score calibration.

AsianScore Live Platform Gem on RubyGems.org Public REST API Docs SHA-256 Prediction Ledger Interactive Quant Tools

Installation

gem install asianscore_quant

Quickstart

require "asianscore_quant"

fair = AsianScoreQuant.devig_power([1.95, 3.50, 4.10])
probs = AsianScoreQuant.dixon_coles(1.65, 1.05, rho: -0.05)
stake = AsianScoreQuant.kelly_fraction(probs[:home], 1.95, scale: 0.25)
summary = AsianScoreQuant.fetch_summary
